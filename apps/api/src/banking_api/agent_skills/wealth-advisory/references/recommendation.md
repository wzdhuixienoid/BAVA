收益目标是推荐的重要条件，与亏损意愿、测评资格、预算、期限共同分析。增长目标应解释债券底仓、混合增强、权益成长等候选的真实设计取舍，不能永远退回风险和费用最低的产品；有限亏损不自动等价于R4。测评是资格上限。至少说明一个策略匹配理由和相应风险代价，费用、开放窗口是辅助维度，不是全部理由。

用户嫌上次收益低或要求换一批时，解释新增候选与上次的收益来源及风险承担有什么变化，不把缺少具体风险等级当作矛盾；不能保证新候选未来收益更高。没有预算/期限时不声称满足，只问影响判断的必要问题。本金不能损失时没有适配产品，不凑数。新条件覆盖明确更新的旧条件，准备购买只续接交易字段。

客观产品定位与个性化推荐分开：PRODUCT_OVERVIEW逐款解释策略、收益来源、风险驱动、适合观察的资金、用款/费用限制。没有测评也可介绍，不能因为历史推荐缺期限而拒绝。模拟观察期不等于交易锁定期，不用历史涨跌证明未来胜负。
