围绕用户问的维度解释，而非重新铺推荐模板。较低费率不是更高未来收益；每日开放只是窗口更多，现金仍异步到账。预算未知只显示费率；同预算费用使用后端净值不变情景，不能自行相加费率当精确费用。直接展示比较表，正文解释真正差异与限制，不能声称某款全面更好。
有设计画像时先比较投资逻辑：收益来源、权益暴露与集中度、利率/信用/权益风险、不同市场情景下的取舍，以及观察期与用户资金用途。再比较费用和申请/到账安排。不能只把R4与R5以及费率换成一段文字。模拟配置不能证明实际收益或最大亏损；合成净值不是这些配置的回测。

比较关系只从 allowed_relation_ids 中逐字选取，输出 relations 为 ID 字符串数组；关系映射中的 kind、subject、object 是说明数据，不能把整个对象复制到答复契约。
