# 订阅管理与消息中心

## 查看订阅

输入“我有哪些订阅？”、“最近有没有涨价的？”或打开 `/subscriptions`。系统从模拟交易识别月度／年度周期扣费，结合合同状态展示费用、涨价及下次续费。

- 可在这里管理：Mock Provider 支持管理的合同，可按状态取消或恢复。
- 需要到商户管理：仅从流水识别的扣费项目，站内不能取消，也不自动扣费。

用户界面用中文说明费用和取消方式，不展示内部英文状态和处理字段。没有实际扣费记录时显示“暂无扣费记录”；已过期的预计续费日期显示“待确认”。检测不判断用户是否真的使用服务。

## 页面确认取消

在订阅管理页面点击“取消订阅”，弹窗中选择“确认取消”。后台持久化取消状态，成功后刷新订阅状态与费用汇总，后续模拟自动扣费停止。“暂不取消”不修改合同。

页面直接取消调用 `POST /api/v1/subscriptions/{id}/cancel`，校验明确确认、用户归属、合同版本、安全写锁、幂等键及可取消性。该能力没有开放给只读 Agent。

## 对话取消与恢复

输入“取消星幕视频”走既有 YELLOW Workflow，核对并明确确认后执行。输入“恢复星幕视频订阅”走 RED Workflow，需要确认及 Mock 强验证。

恢复原套餐的未来续费授权，本次不立即扣费。仍有效的未来账期保留，过期时按原周期推进；只有 Provider 允许恢复的可管理合同支持此操作。

取消和恢复的结果以持久化业务状态为准，Task 完成或点击链接不能作为成功凭据。

## 续费提醒与模拟扣费

消息 Worker 默认每 30 秒检查一次。每期扣费前 7 天内生成一次站内续费提醒；每个账期的扣费结果也生成一次提醒。持久化游标及去重键防止已读或删除后的同一消息再次生成。

Docker 示例启用 `MOCK_SUBSCRIPTION_BILLING_ENABLED=true`。仅 development/test 可开启，模型 Settings 默认关闭。到期可管理合同由模拟扣费账本处理；余额不足或安全锁定时提示失败、不扣款。示例合同绑定工资卡，其他仅检测项不自动扣费。

首次启用不补扣旧账期，不推送已有历史流水；之后根据持久扫描进度恢复。扣费使用 Worker 的实际时间；`DEMO_REFERENCE_TIME` 不能用于推进真实授权 TTL 或模拟扣费调度。

## 消息中心

工作台消息入口显示未读圆点，可查看、标为已读和删除。订阅续费、扣费及预约每期执行结果均使用站内消息。没有短信、邮箱或外部推送渠道。

消息按用户归属隔离。删除消息不删除账本、业务结果或审计记录。
