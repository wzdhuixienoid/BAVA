# 账户、账单与消费报告

## 查询账户

在工作台输入“我有哪些账户？”或“工资卡余额多少？”。账户卡显示工具返回的账户名称、尾号、余额和查询时间。信用卡负余额表示欠款，不作为可用存款；多币种账户分别展示。

账户查询结果是当时快照。转账或模拟订阅扣费之后，需要重新查询或刷新总览获取有效余额。

## 查询已入账账单

在工作台输入“我最近有哪些转账”“查看上月工资卡的购物明细”“查询今年订阅扣费记录”或“查看最近理财资金流水”。未指定期间默认近30天；可指定自然年/月、最近N天、日期区间、账户、类别、转入/转出和对手方姓名。默认每页10条，最多50条；有更多记录时输入“下一页”，继续同一期间和筛选条件。

账单展示实际入账时间、对手方、账户、方向及带正负号的金额，与金融总览账单共用数据。订阅续费提醒、待处理/失败转账、未执行预约和理财资金冻结均不等于已入账扣费。没有匹配流水时只说明所查范围内没有已入账记录；不能据此判定从未发起过交易。查询不会执行转账或推进结算。付款方姓名未由银行提供时显示“转账收入”，不猜姓名。

## 选择分析期间

| 输入 | 期间与结果 |
| --- | --- |
| 分析一下最近的消费 | 默认业务时间向前 30 天，并说明区间 |
| 分析工资卡最近 45 天的消费 | 同账户连续区间，可跨月或跨年 |
| 为什么 2026 年 8 月花这么多？ | 指定自然月的汇总、分类及实际查询的交易 |
| 分析 2025 年消费 | 自然年分析与上年比较，受可用数据限制 |
| 分析 2026 年 8 月 1 日到 8 月 15 日的消费 | 明确时间范围，无法确定时要求补充 |

未指定年份的月份按业务参考日期补全年份。“本月”使用当前业务月。最近 N 天比较紧邻的等长前期；月度与年度分别按环比和同比。回答会说明实际使用的期间与数据限制。

金融总览在 `/dashboard`，默认消费查询月份为当前北京时间月份，可选择年份、月份并刷新。账户下的账单明细独立展示已入账收入和支出，可按年月、类别和账户筛选，包含成功订阅扣费、理财现金流水及转账收支。未来续费提醒和待成交订单尚未形成新的现金账单；理财份额变化及费用辅助记录不重复计为扣款。

## 异常提示

消费汇总默认附最多 3 条优先核对提示，重复扣款和订阅涨价优先；明确拒绝异常检查时跳过。需要完整分析时输入“最近有没有异常交易？”或明确一年以内的查询范围。

系统说明规则、比较基线与证据，最多显示 50 笔并注明截断。样本不足或范围超限会说明原因，仍可完成普通消费汇总。异常提示不代表已确认欺诈，未检出也不代表排除风险。

## 生成与管理报告

输入“生成一份 2026 年 8 月份消费报告”或“生成一份 2025 年消费报告”。生成成功后可从对话报告卡打开，也可在 `/reports` 查看历史报告。

报告保存当时的可信快照，包括期间、核心指标、分类、主要交易、比较与核对提示。删除和恢复改变可见性，不重新计算历史数据。没有有效数据时说明原因，不生成空报告。

内部 Skill ID 与存储类型沿用月度标识兼容历史数据，`period` 使用 `YYYY` 或 `YYYY-MM` 区分年报和月报；界面按实际期间展示。

## 模拟数据

提交的交易 fixture 覆盖 2025-01-01 至 2026-10-07，共 1,207 笔：21 个完整自然月和当月部分数据，包含收入、退款、分类消费、订阅历史、转账、待入账、撤销及异常样例。它是固定种子生成的数据，不会自动生成未来完整账单。

账单 fixture 与数据库中的对话、业务和审计分开。再生成后重启 API 读取新 fixture；不需要清空数据库。生成与黄金数据校验命令见 [测试与演示](../development/testing.md)。
