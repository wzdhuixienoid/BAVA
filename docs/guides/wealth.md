# 模拟理财

理财中心 `/wealth` 与工作台提供八款虚构人民币开放式净值型产品。全部无本金或收益保证，不另收持续管理费。净值、近 30 日变化及最大回撤来自独立合成历史，不是策略组合回测。

## 浏览、测评与推荐

未测评也可查看完整目录、资料和客观对比；目录不要求先填预算或用款时间。个性化推荐和新申购要求本人有效、适合的风险测评。页面“个性化推荐”和“对比所选产品”转到工作台发送需求，由对话展示结果。

1. 开启 `MOCK_WEALTH_ENABLED=true`，迁移数据库并重启 API。启动幂等导入共享产品、净值、说明书、风险提示与 FAQ，不生成持仓或扣款。Settings 默认关闭，Docker 示例开启，production 拒绝开启。
2. 在理财中心逐题完成 8 题问卷，答案 0–4 分；版本 mock-v1，有效 12 个日历月。重要信息变化时重新测评，旧记录保留。这是项目 Mock 规则，不是法定评估标准。
3. 输入本次目标、预算、亏损意愿和用款时间，可选本人账户。最多推荐 3 款；对比最多选择 4 款。
4. 查看正文中的理由、取舍、风险、条件与问题，以及产品卡的费用、开放时间、净值、资料和购买入口。

```text
有哪些模拟理财产品？
预算5千，希望有收益，能接受部分亏损。
为什么第一款？和第二款比呢？
还有其他产品推荐吗？
比较演示稳健优选和演示进取成长。
你对每个产品的定位是什么？
下周可能用钱，还适合吗？
```

推荐先检查资格、预算、风险上限和流动性，再比较策略。明确偏好时比较偏好距离、风险、开放日及费率；增长诉求参考模拟设计的权益参与度，不提高测评等级或承诺收益。换一批保留约束并排除此前候选，逐款定位属于客观介绍。

测评 C1–C5 对应产品 R1–R5 上限。总分区间为 0–6、7–12、13–19、20–25、26–32；损失承受选项还会限制等级。要求保本、不能接受损失或即时用钱时，无适合申购的产品。无适配返回原因，不放宽条件凑数。测评等级不是购买同等级产品的要求。

预算支持元／千／万／亿、常用中文数及规范千分位，使用 Decimal 校验。范围、多金额或矛盾条件先核对。“能接受部分亏损”不能推断最大亏损保护，“不要求保本”不能误判为保本要求。

## 连续追问与依据

“第一款”“第二款”按本人本对话实际展示顺序解释，多个可能的“这个”先选择。新条件按 SET／CLEAR／KEEP 合并后重新筛选；“上次为什么”解释原快照，“现在还能买吗”重新查询当前事实。

新对话不继承其他对话预算、意愿和候选。已保存测评属于本人账户资料，但问卷目标不代表本次资金目标；仅参考问卷时明确标注。

资料区分 Mock 条款、通用教育与项目模拟设计画像。画像比例是虚构组合目标，不是实际持仓，也不预测合成收益。观察期仅供分析，不是赎回限制。资料链接打开绑定版本，缺少证据明确说明。历史订单使用原资料版本，不拿新画像解释过去交易。

费用情景显著说明净值不变等假设；到账分析区分现在赎回和新申购后最早赎回，计算至现金实际到账。未来金额与预计时间均不保证。

模型结合已校验事实和检索资料生成正文，关键数字由后端插入并检查引用和比较关系。失败最多修复一次，再展示同一事实的基础说明。快照保存事实、顺序、资料版本及参考时间；刷新不自动调用模型或改写旧结论，可主动“按当前条件重新分析”。

## 从购买意向到申购

“我想买理财”先进入只读选购；未测评先引导测评。“我完成了风险测评”会重新读取本人实际记录，口头声明不解锁交易。指定产品但字段不全时先介绍并提供购买入口，不创建空订单。

点击产品卡“购买…”展开账户与金额输入，填写后“下一步：核对申购”才创建持久草稿；重复点击使用同一创建键。完整指令如“从工资卡申购演示稳健优选1000元”可直接进入核对流程。

1. 选择本人有效人民币借记／储蓄账户、产品及总金额，满足测评与起购要求。
2. 核对估算费用、份额、交易日、原条款和预计成交时间。
3. 明确确认，完成 强验证并提交；默认确认有效 600 秒、强验证 300 秒。
4. 受理后资金被占用，等待成交；最终结算时扣款、退款及份额同事务入账。

核对卡估算不是实际成交。跨截止点、测评、条款或字段变化须重新核对与授权。没有有效测评时不创建新申购草稿，已有未提交草稿可取消。

## 赎回与单位

赎回限定本人持仓的原付款账户，填写份额，确认及强验证后提交。受理冻结份额，成交扣减份额，现金到账前单列为待到账，不计入可用余额。测评失效或风险下降不阻止已有持仓赎回。

申购用“元”，赎回用“份”。“赎回100元”不会改成100份；单位缺失、矛盾或多数量时先补全。“全部赎回”使用后端明确可用份额字符串。无持仓、份额为零或不能唯一确定产品／账户时拒绝或先选择。核对后份额被占用会拒绝提交，不静默减量。

## 交易时间与金额规则

模拟交易日为北京时间周一至周五，不处理真实节假日。严格早于 15:00 归当日开放日，15:00 及以后顺延；周开放产品按自身窗口。交易日 18:00 发布净值，下一模拟交易日 10:00 确认；赎回再下一模拟交易日 10:00 到账。

金额两位小数，净值／份额六位；费用和现金四舍五入，申购份额向下舍入，余款为总金额减费用与份额价款。无法形成正份额或非负退款时拒绝。缺少已发布净值不能交易或估值，不默认净值为 1。

## 状态、通知与删除

| 状态 | 含义 |
| --- | --- |
| 草稿／待确认／待验证 | 尚未受理，可修改或取消；修改使旧授权失效 |
| 已受理待成交 | 资金或份额被占用，不代表已成交 |
| 已成交待到账 | 赎回份额已扣减，现金尚未到账 |
| 最终完成 | 申购份额入账或赎回现金到账 |
| UNKNOWN | 原操作结果确认中，保留占用，继续恢复 |
| 明确失败 | 展示原因与下一步，按实际状态释放未结算占用 |

受理后对话显示“申请已提交，成交后会通知你”，结束本次回复动画；后台继续原订单，只有 SETTLED 才投影最终资金成功。成交／到账通知展示实际份额和现金结果，按阶段去重。只读 GET 不推进结算，不应重复下单。受理后不可撤单，安全写锁不阻止已有订单兑付。

持仓、订单、余额、测评及 Workflow 统一刷新；隐藏页面暂停，重新可见即刷新，请求不重叠。失败保留旧数据并提示重试。编辑期间不覆盖未保存输入；版本冲突须重新核对，不自动重试提交。

满足关联证据要求的已受理理财对话可软删除；订单、占用、账本、恢复及审计仍在理财中心保留。未提交草稿须先取消，无受理证据的 UNKNOWN 和其他活动任务仍阻止删除。删除对话不撤单。

## 暂停与限制

关闭 `MOCK_WEALTH_ENABLED` 并重启后，暂停新测评、草稿、授权和首次受理；查询及取消未提交草稿仍可用。已受理订单、UNKNOWN 原操作继续成交／到账。未受理操作明确拒绝且不冻结资金。production 禁止 Mock 执行。

净值 fixture 为 2025-01-01 至 2027-12-31，未来记录不可提前读取。超出范围的订单缺少成交日净值时等待并保留占用，不能伪造成交。理财资金流水进入账单，但本金、退款和费用辅助记录不混入日常消费／收入统计。

不支持条件自动投资、多笔写业务、定投、调仓、封闭式产品、基金、真实渠道、部分成交及受理后撤单；有条件的交易请求整体拒绝，不丢弃条件执行。
