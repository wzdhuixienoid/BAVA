# 免密支付额度与身份验证

## 金融总览中的额度设置

从工作台进入“金融总览”，在账单明细与消费年月筛选栏之间设置本人的单笔免密额度。默认200元，范围0—200元，精确到分；0关闭免密。核对新额度后，输入本人已设置的身份验证码，再点击“确认并验证”。设置按本人保存，有版本冲突时刷新后重新核对。

只有「单笔金额严格小于个人额度」和「含本笔的当日成功累计及执行中敞口不超过1000元」同时成立，才进入黄色确认。单笔达到额度或日累计超过1000元须红色验证。预约及周期授权保留红色验证。提交时重新校验最新额度，不能用旧确认跳过升级后的验证。

原“安全中心与操作记录”独立页面已移除，旧 `/security` 地址自动跳转金融总览。

## 身份验证码保密

本地验证使用后端私密环境中的 `MOCK_REAUTH_CODE`，按用户已设定且本人知晓的身份验证码处理。不通过页面、前端构建参数、状态接口或OpenAPI返回该值。额度修改与红色业务只提供密码型输入框，验证码验证后立即从页面状态清除。

部署者在私密 `.env` 中配置该值，再重启API生效。切换验证方式的脚本保留已有验证码、模型参数及加密密钥，不自动重置用户选择的验证码。生产继续禁止Mock验证；本地环境码只能验证模拟流程，不能当作真实第二因素。

## 后端审计

订阅查询仍需明确确认，授权5分钟；取消、恢复使用各自授权。页面取消、额度修改和查询授权等记录通过后端 `/api/v1/security/audit` 按本人查询，不再提供独立操作记录页面。对话中的审计入口保留。记录不包含验证码、认证器密钥或原始请求正文。

## 认证器动态码

部署者可使用[完整登录与动态码环境](../development/oidc-demo.md)或 `scripts/configure_local_mfa.py --method totp` 启用TOTP。登录后在金融总览的“认证器验证”中绑定本人认证器，输入当前动态码确认；成功后页面清除绑定密钥。OIDC模式绑定要求5分钟内的主身份认证。绑定过或已经授权过的动态码不能再次用于交易，使用认证器随后生成的新动态码。

TOTP采用 [RFC 6238](https://www.rfc-editor.org/rfc/rfc6238)，密钥使用 [Fernet](https://cryptography.io/en/latest/fernet/) 加密，动态码防重放及失败锁定继续执行。生产身份、私密配置和数据库升级见[环境说明](../development/setup.md)。
