## 真实模型与表达集

模型：已有配置 deepseek-v4-flash，现有 OpenAI-compatible 适配器及 LangGraph。真实调用与 FakeLLM 分开。

50 条表达：开发 40，保留改写 10。真实提取最终 action + 精确金额 gold 为 **50/50**（40/40、10/10）；48 条 MODEL_EXTRACTED、2 条有限修复后 DETERMINISTIC_FALLBACK，不能把全部50条当作模型理解成功。这个分母仅衡量这两个标注字段，不等于全部金融语义正确率；对象归属、范围、SET/CLEAR/KEEP、指代与交易边界另有行为测试。早期评估出现约数被当精确、类别被当具体产品等错误，修正后重跑；不把旧失败掩盖成最终成功。

最后一轮 12 个独立场景，**11 个 MODEL_GENERATED、1 个 DETERMINISTIC_FALLBACK**。覆盖：五千普通收益/有限亏损；5k 半年稳健；0.5万两产品费用；指定产品理由；必须保本；10%有限亏损；下周不确定用款；选中产品；用工资卡三千五百；最大回撤/低风险不保证；R2 上限/否定进取；目录。

失败样例：“比较演示均衡优选和演示均衡周享，投0.5万元手续费差多少？”模型两次将关系 ID 输出成对象，契约拒绝，最终降级。后端金额仍为 5000，费用情景差 4.99 元，表格/已核验解释仍可用，无金融写入。独立场景不是完整浏览器交易通过率。

人工复核实际段落与事实/来源：金额、风险上限、费率情景、无保本、下周用款阻断、准备阶段、来源作用域均核对。发现并修正：用户 R2 上限被产品 R1 字段替代、准备交易扩写费用日期、一般教育风险被写成 Mock 暂停赎回条款、下周“用到钱”范围遗漏。浏览器又发现无“理财”关键词的首句绕过统一理解，已补入口和正向持久任务断言。

仍有质量问题：个别正文把“为每日开放多付费”说得过于泛化，或重复风险/估算说明；不能把 11 次契约通过宣称为自然文字完全无误。关系/引用校验不证明全部开放语义，保留人工复核和诚实降级。无新增收益预测、资产配置或交易授权能力。
