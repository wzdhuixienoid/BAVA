## 身份与动态码验证

独立 Keycloak 26.8.1 完成密码登录、OIDC Authorization Code + PKCE（S256）和 JWT 验签；错误 audience 与无凭据请求被拒绝，近期主身份认证信息被正确识别。金融总览完成认证器绑定，错误动态码被拒绝，成功绑定后页面清除密钥。

交易验证使用独立 RFC6238 动态码生成器，执行真实 TOTP 校验。红色业务在用户确认、动态码验证和显式提交后完成模拟入账；验证失败阶段没有创建资金 Operation。数据库回归另外覆盖动态码并发消费、防重放及凭据保留。复现见[完整登录与动态码环境](../development/oidc-demo.md)。
