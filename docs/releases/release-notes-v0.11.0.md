# v0.11.0：模拟净值型理财

新增理财中心、只读 WealthAdvisorAgent、申购和赎回 Workflow、持久 MockWealthProvider。8个虚构产品、版本资料、固定种子净值、本人风险问卷、确定性推荐及对比、持仓、订单和资料问答组成 Mock 闭环。运行时继续 LangGraph；模型只解释工具事实。

共享账户余额与稳定账户锁从转账Provider抽出，转账、AA、订阅、Dashboard及理财读取同一余额。申购冻结/扣款/退款、赎回冻结/扣份额/待到账/入账由独立账本和短事务完成。申购与赎回均确认及强验证，授权绑定条款、测评与交易日期，跨截止点重新授权。OperationRecoveryWorker负责异步成交、到账、lease恢复及原订单幂等查询。

Alembic0034顺接0033，新增共享目录、不可变版本、净值、文档、测评、订单、持仓、占用和账本，并扩展共享业务enum。无业务数据可降级删除理财表，保留共享enum新值；有理财工作流、订单、持仓或测评时拒绝破坏性降级。不能清空演示库升级。

`MOCK_WEALTH_ENABLED` 默认false；Docker development示例开启，production拒绝。已受理订单可在关闭新业务后继续恢复，安全写锁也不阻塞已受理结算。启用时幂等导入不覆盖冲突版本。

新增 `scripts/smoke_wealth.py` 只允许独立PostgreSQL测试库，使用私有注入时钟和确定性断言完成测评至赎回到账，并验证受理后超时零重复扣款。
