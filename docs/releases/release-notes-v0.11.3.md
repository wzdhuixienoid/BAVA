# v0.11.3：个人银行账单与转账历史修复

交付日期：2026-10-15。应用、API、网页、包版本与当前文档统一为 **0.11.3**；不新增数据库迁移，Alembic head 仍为 0034。下方保留同版本号的早期理财发布记录。

## 本轮行为

- 修复“我最近有哪些转账”无法查询：新增 R1 只读 `get_account_statement`，仅对 PersonalBankingAgent 的 ACCOUNT/COMBINED 配置开放；与金融总览共用已入账账单服务。
- 可查转出/转入、购物等日常收支、工资收入、订阅实际扣费、理财申购/赎回到账/退款。支持期间、账户、类别、方向、来源与对手方/备注筛选，默认最近30天和每页10条，最多50条。
- 明确区分“查询转账历史”和“发起转账”；历史加写操作仍走受约束计划和原授权链路。纯查询不会调用提交、恢复或推进结算的工具。
- 纯账单回复与网页清单直接使用验证后的银行事实；成功结果保存 `statement_results` 和 `statement_queries`。模型生成的拒绝或错误金额不能覆盖已取得的账单事实。
- 转账回复采用与消费分析一致的正文：分析区间、转出/转入总额及笔数、收款人/付款方金额与占比、简短解读、最近一笔及明细。Decimal汇总覆盖全部匹配记录，分页只影响明细。
- 收款人按本人可见的唯一标识分组，同名时展示银行和账户尾号；币种和收支方向分别统计，资料不足时只按账单名称归集并明确说明。
- 旧结果保存完整明细时，可从历史快照派生新展示；不读取新流水、不改写旧记录。旧结果只有部分明细时不推算总额，提示重新查询。
- “下一页”只继承本人本对话最近完成的账单查询，复用筛选、期间、截止时刻和偏移。普通新查询不继承历史月份；翻完明确说明。
- 待处理、失败、未执行预约、续费提醒及冻结不作为已入账事实。删除收款人不会让历史转出的收款人姓名丢失；未提供的付款方姓名不编造。
- 工具总数更新为27：19个纯读取、5个提交、3个会推进状态的对账工具。banking-assistance 标准技能包更新到0.12.7；资源版本与应用版本独立。
- 真实模型验收发现“转给某人”可能遗漏转出方向，已在Skill和双运行时补齐明确方向约束；连续翻页的原条件、截止时刻及偏移由执行层固定。

## 历史记录：理财语义、技能与分析链路

本轮将自然表达、本人本对话的需求更新、只读顾问分析和交易补全接入同一份版本化意图。保留 Mock 开放式净值型产品、LangGraph、原有 Workflow/Operation、确认、身份验证及恢复机制。

## 行为变化

- 共享 Decimal 解析支持 5千、五千、5k/5K、0.5万、人民币符号及千分位。范围、约数、应急留存金额、份额、日期及百分比分开核验；未知单位不会截取数字前缀。
- 收益目标和有限亏损意愿独立于风险等级。C5 不再默认导向 R4；明确改变个人条件通过 SET/CLEAR/KEEP 更新，不修改测评。
- 推荐、比较、解释、目录、知识问答与准备交易分别处理。选中产品后只补交易金额和本人账户；后续消息续接真实草稿，修改使旧授权失效，不重复创建金融操作。
- 当前推荐/比较顺序、需求及准备交易信息保存于本人本对话 Task JSON。新对话和新计划不继承旧需求；超过十条普通消息仍可读取有效快照。
- 两个应用 Agent Skills 从可信包发现，按模式激活并加载 SKILL.md 和必要参考资源。版本、资源 hash、激活和完成事件可审计。它们不能增加只读 Agent 的交易权限。
- 现有模型通过 LangGraph 和真实只读工具组织新分析文字。唯一 WealthAnswer 保存正文、事实/证据引用、生成来源、技能版本和关联 Workflow；不再让模型仅排列模板编号。
- 关键金融数字通过 typed fact 插值；比较关系由后端核验。校验失败最多修复一次，仍失败则显示已核验事实的短解释，并如实标注降级。
- 比较表直接可见；卡片资料与底部实际引用按版本去重。准备交易布局不再重复推荐阶段问题。旧结果保留历史事实，不自动重算或改写。

## 原问题修复对照

| 原问题 | 当前行为 |
| --- | --- |
| 5千/5k 被读成 5 元 | 精确规范化为 5000；不认识的 5xyz 要求澄清 |
| 想赚钱、有限亏损被忽略，C5 默认 R4 | 普通收益目标与亏损意愿保存；未指定风险时保守比较 |
| 已选产品仍问推荐期限/亏损 | 切换购买补全，只处理金额、账户和具体资格阻断 |
| 从/用工资卡、预算前置改变路由 | 共用意图与数量核验，完整交易字段进入待核对 |
| 模型只能排列固定文字 | 生成新正文、调用真实只读工具并核验事实 |
| Python 呈现类被称为 Skill | 标准 SKILL.md 包真实发现/加载/激活；Python 类仅为降级呈现 |
| 比较折叠、24 份资料重复 | 直接表格，卡片保留资料，底部仅补充实际依据 |
| 不能亏变为接受有限亏损仍保留旧条件 | 更新个人损失要求，不改变问卷或提供止损保证 |

## 限制

产品资料未披露资产配置、债券/股票敞口和发行人信用质量，不能由名称或风险等级推断。模拟历史不是收益预测；现金链路是 Mock 工作日日历下的估算，不保证现实银行到账。开放语言的事实引用检查不是完整语义证明，仍可能出现措辞重复或过长；失败记录和人工复核必须保留。解析不明确时澄清，不据此创建可提交数量。
