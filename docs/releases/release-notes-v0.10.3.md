# v0.10.3 更新说明

本版完善消息提醒与订阅管理，所有扣费仍使用模拟环境。

- 消息中心：未读圆点、查看消息、标为已读与删除；预约转账每期执行产生结果提醒。
- 订阅提醒：每期扣费前 7 天通知一次，模拟扣费时通知一次，取消后停止后续扣费。
- 直接取消：订阅管理页面点击“取消订阅”，在弹窗中确认后持久化取消状态，并刷新费用汇总。
- 易读报告：去掉后台英文标记、字段和处理逻辑，金额保留 ¥ 符号，无扣费记录和过期预计日期分别显示“暂无扣费记录”和“待确认”。
- 统一导航：入口改为“订阅管理”，与相邻模块保持相同样式。
- 工作台标题：版本号更新为 v0.10.3，放在“智能银行服务”右侧；删除标题下方的版本与功能说明。

数据库迁移目标为 `0033`，升级时运行 `alembic upgrade head`，保留已有业务数据。页面内取消接口继续校验订阅归属、安全写锁、合同版本和幂等键；对话中的写操作仍走原有 Workflow。
