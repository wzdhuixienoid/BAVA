# v0.11.4：理解策略、解释取舍和继续推荐

版本日期：2026-10-12。数据库仍为 Alembic 0034，无新迁移。

原推荐默认贴近最低风险，增长目标不改变候选；“这些产品”被当成单款选择，客观定位问题也回到条件澄清。原产品资料只有交易参数，模型无法有依据地分析投资逻辑。

本版为八款虚构产品加入独立的 `mock-design-v1` 画像：现金短债、债券票息、混合增强、分散权益成长、主题权益集中。资料包含模拟组合目标、收益来源、风险驱动、市场情景、适合及不适合观察的资金、参考观察期。发布于 2026-10-12 08:00 北京时间；旧条款、合成净值和历史订单保持原版本。

推荐在本人测评、明确风险上限、起购和用款限制内，结合本次增长目标选择不同策略作比较。“收益太低，换一批”保留预算与硬条件，寻找此前未介绍的候选，并给模型上一批的策略摘要。不会把用户的收益评价当作已核实表现，也不会据此提高测评等级。“只看 R2 以下”重新筛选。客观的逐款定位介绍不要求投资期限或测评。

正文由现有模型结合应用 Agent Skills、只读工具和已核验资料生成；关键数字与比较关系经后端核验。支持有资料依据的自然改写，校验失败最多修复一次，仍失败则显示确定性降级说明。技能按模式加载推荐、比较或定位参考资源，保存技能版本与资源 hash。

前端增加正文小标题，比较表直接显示策略、收益来源、主要风险、观察期、风险等级、开放、费用和现金到账。产品卡给出一句定位，已有产品文件在来源区去重，新模拟设计可打开阅读。窄屏表格可横向滚动。

画像是项目编写的模拟设计，不能称为银行披露、实际持仓或收益预测。合成净值独立生成，不是该组合的回测。观察期不是锁定期，费用、申赎和到账继续由原交易条款决定。推荐与资料问答不建立金融操作，购买仍经过原核对、确认和强验证。

验证方式与本轮实际结果见 [验收记录](../development/wealth-v0.11.4-evaluation.md)。
