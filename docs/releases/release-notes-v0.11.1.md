# v0.11.1：理财修复与体验优化

修复关闭新业务后重启丢失恢复工具的问题：development/test始终注册只读和受控恢复能力；首次受理检查开关，已有订单重放返回原结果，原Operation继续成交及到账。未受理请求关闭时明确失败，不占用。生产Mock执行仍禁止。新增理财状态接口，暂停时页面继续展示持仓、订单、资料和进度，可取消未提交草稿。

修复自然语言丢弃元/份单位的问题：提取保留单位，错配、缺单位、多数量和不规范金额先澄清。全部赎回由后端唯一确定持仓、固定可用份额字符串，核对及强验证后提交再检查，不静默减量。条件自动投资和多笔交易拒绝逻辑保留。

修复推荐忽略本次保本/否定要求的问题：HTTP与Agent共用结构化约束解析和确定性筛选。测评只作为风险上限；保本、不接受损失、即时用钱和明确排除偏好均为额外约束。无法可靠理解或冲突时要求补充，无适配产品不放宽条件。推荐产品权限标记依据当前用户测评。

订单结果新增兼容性typed字段：错误码、中文原因、下一步、最后已知阶段、下次预计处理时间和占用状态；页面及对话结果卡共用说明。保留失败订单的对话和审计入口。动态资源统一刷新，静态资料按版本加载，隐藏暂停、请求不重叠、失败保留旧内容。交易编辑不被轮询覆盖，版本冲突不自动重试提交，创建草稿和对话同事务、创建键幂等。

新增接口：`GET /api/v1/wealth/status`、`GET /api/v1/wealth/workflows`。创建Workflow支持省略conversation_id并在同事务生成本人Conversation/Message/Task，支持creation_key和redeem_all。持仓新增available_quantity原始Decimal字符串，更新OpenAPI客户端。无新迁移，head保持0034，历史迁移及账本不修改。

以下为本轮实际执行结果；v0.11.0的历史820项记录不作为本轮证据。仍仅Mock开放式净值型，无真实金融接入、自动投资、向量库或持仓收益体系。需求解析支持列明的常见中文表达，复杂或不明确表达需用户补充。
